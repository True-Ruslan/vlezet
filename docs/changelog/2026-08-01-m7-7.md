# M7.7 — Furniture and Fit Workflow

**Date:** 2026-08-01  
**PR:** #35  
**Status:** automated acceptance passed; product-owner browser review pending.

## Why

Furniture capabilities were already precise and authoritative, but they did not yet feel like one ordinary-user workflow:

- known items required scanning a long static catalogue;
- exact coordinates competed visually with common resize and rotate actions;
- object-local front/right/back/left clearances were not mapped clearly after rotation;
- one generic Apply error obscured which field needed correction;
- dimensions, recommended use zones and actual free distances could be confused on Canvas.

M7.7 resolves `UX-FURN-001`, `UX-FURN-002`, `UX-FURN-003` and the remaining `UX-FURN-004` without changing M2 fit authority.

## Delivered

### Catalogue and placement

- deterministic search with Russian text normalisation;
- category chips combined with search;
- stable result order and visible counts;
- empty-state reset;
- runtime-only filter state;
- existing one-item placement command preserved;
- M2-derived non-colour placement fit label.

### Selected-object editing

- fit result first;
- common identity, dimensions and exact rotation next;
- use-zone explanation before advanced coordinates;
- exactly one `Повернуть 90°` command;
- one atomic exact-edit Apply and one semantic Undo step;
- all local errors reported together;
- invalid hidden sections automatically revealed and focused;
- stale drafts cleared through authoritative object identity.

### Orientation and evidence

- store-free exact-angle orientation cue;
- correct local front/right/back/left meaning at cardinal and diagonal rotations;
- explicit `Рекомендуется` versus `Свободно сейчас` copy;
- Canvas legend for size, recommended zone and current free distance;
- planning label `Кратчайший зазор` for nearest rotated contours;
- compact-width and readable 12 px helper typography.

## Architecture preserved

No changes were made to:

- `VlezetDocument`, schema, migrations, IndexedDB or backup format;
- M2 containment, collisions, door conflicts, clearance or fit calculations;
- object snapping and gesture authority;
- editor-core semantic commands and history grouping;
- planning, recognition or 3D authority.

No automatic movement, rotation, resize or repair was introduced.
