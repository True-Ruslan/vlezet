## Region-first local recognition

- Otsu binary inversion and bounded morphological opening produce a thick structural raster.
- A deterministic scanner extracts stable horizontal and vertical filled wall bands.
- Bands must satisfy overlap, run-length similarity, physical thickness, minimum length and aspect-ratio constraints.
- Each accepted wall region becomes exactly two boundary segments for deterministic centreline/topology construction.
- Canny/Hough runs only as a fallback when fewer than three structural regions exist.
- Local candidate explosions above 80 walls fail closed before persistence and AI review.
- Persisted overloaded Drafts are sanitised on restore.
- Local openings remain deferred until M7.8C.

## Verification-only AI review

The previous provider prompt sent the image and only the number of local candidates. GPT-4o therefore re-recognised the plan instead of checking the local Draft.

The updated path now:

- sends every local wall ID and exact coordinates;
- forbids new wall IDs and geometry;
- requires returned walls to preserve ID and coordinates;
- allows AI only to confirm/reject candidates and provide confidence/score;
- requires `openings: []` in M7.8B;
- rejects unknown cloud IDs before reconciliation;
- rejects known IDs with substituted geometry;
- rejects unsupported full-frame lines and candidate explosions;
- never appends unmatched cloud walls/openings;
- never moves local wall endpoints;
- preserves local geometry as the only recognition authority.

The repeated product-owner test confirms that these constraints work on the representative plan. AI can no longer hide missing local geometry by inventing topology.
